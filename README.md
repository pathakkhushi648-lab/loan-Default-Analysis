# Loan Default Analysis Project

## Project Overview

The Loan Default Analysis Project is a complete data analysis project that studies customer financial behavior and identifies factors affecting loan default risk. This project uses Exploratory Data Analysis (EDA), statistics, probability, visualization, and linear algebra concepts to analyze customer loan data.

The project helps financial institutions understand customer repayment behavior, identify risky customers, and improve loan approval decisions.

---

# Objectives

- Analyze customer financial data
- Identify factors affecting loan default
- Perform complete Exploratory Data Analysis (EDA)
- Apply statistical and probability concepts
- Visualize customer financial behavior
- Calculate default probability
- Perform vector and linear algebra operations
- Build a foundation for machine learning models

| Credit_Score | Financial credit score |

# Statistical Concepts Used

## Mean
Measures average customer income.

## Median
Measures middle income value.

## Mode
Measures most frequent value.

## Range
Measures total spread of loan amount.

## Variance
Measures variability in financial data.

## Standard Deviation
Measures average deviation from mean.

# Key Insights

- Customers with lower credit scores show higher default probability.
- Income positively correlates with loan amount.
- Some customers show high financial variability.
- Loan term affects repayment behavior.
